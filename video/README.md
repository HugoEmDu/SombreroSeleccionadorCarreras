# Videos del Sombrero Seleccionador

Colocar los videos en esta carpeta antes del evento.
El servidor local los sirve automáticamente.

## Lista de videos requeridos

| Archivo              | Descripción                                      | Cuándo se usa                        |
|----------------------|--------------------------------------------------|--------------------------------------|
| `intro.mp4`          | Video de intro / animación del sombrero          | Al abrir la aplicación (opcional)    |
| `pensando_1.mp4`     | El sombrero "piensa" — variante 1                | Durante el quiz, aleatoriamente      |
| `pensando_2.mp4`     | El sombrero "piensa" — variante 2                | Durante el quiz, aleatoriamente      |
| `pensando_3.mp4`     | El sombrero "piensa" — variante 3                | Durante el quiz, aleatoriamente      |
| `pensando_4.mp4`     | El sombrero "piensa" — variante 4                | Durante el quiz, aleatoriamente      |
| `pensando_5.mp4`     | El sombrero "piensa" — variante 5                | Durante el quiz, aleatoriamente      |
| `resultado_sistemas.mp4`         | Resultado: Ingeniería en Sistemas    | Al mostrar resultado                 |
| `resultado_quimica.mp4`          | Resultado: Ingeniería Química        | Al mostrar resultado                 |
| `resultado_electromecanica.mp4`  | Resultado: Electromecánica           | Al mostrar resultado                 |
| `resultado_mecatronica.mp4`      | Resultado: Mecatrónica               | Al mostrar resultado                 |
| `resultado_administracion_rural.mp4` | Resultado: Adm. Rural           | Al mostrar resultado                 |

## Notas

- Formato recomendado: **MP4 (H.264)**, compatible con todos los navegadores sin necesidad de internet.
- Resolución sugerida: 1280x720 o 1920x1080.
- Si algún video no existe, la app funciona igual (el video simplemente no se muestra).
- Para agregar la reproducción de videos al juego, avisarle a Antigravity para integrarlos al `app.js`.
